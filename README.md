# magicsquare (Luanti Mod)

This mod has been greatly expanded from it's original vision. It now allows picking up mobs and blocks including those with storage. Left click any block or mob with a magic square and right click to release at a desired location.

A configuration file is included for players and servers so that certain blocks can be blacklisted. Mobs can be blacklisted as well and the block pick up or mob pick up functionality can be turned off depending on the needs of the server in an attempt to provide as much customization as possible.

Tested in MTG, Voxellibre, Mineclonia, and chests to ensure that contents are not lost from storage. Also tested wolf mobs from both Mineclonia and Voxellibre (tamed wolves) to ensure no metadata is lost. This should allow moving any entity.

Can be crafted with all sticks except the middle.
